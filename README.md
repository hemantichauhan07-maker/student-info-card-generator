# 🎓 Student Info Card Generator

A simple and interactive **Student Info Card Generator** built using HTML, CSS, and JavaScript.

This project allows users to enter student details such as name, roll number, email, age, gender, course, marks, and student photo. After submitting the form, the entered information is displayed in a clean student information card.

## 🚀 Features

- Enter student name and roll number
- Add student email and age
- Select gender
- Select course
- Set student marks using a range slider
- Upload student photo
- Generate a student information card
- Simple and clean user interface
- Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
